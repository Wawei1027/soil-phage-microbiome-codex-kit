# Smoke Test Prompts

Use these prompts after installing the plugin to confirm that the skills trigger correctly. Replace bracketed placeholders with your own non-sensitive information.

## Project planning

```text
Use the soil-phage-project-planner skill to design a metadata table and analysis plan for a soil phage metagenomics project with treatment, timepoint, site, depth, and soil chemistry variables.
```

## Amplicon workflow

```text
Use the amplicon-microbiome-pipeline skill to draft a QIIME 2 and DADA2 workflow for soil 16S data, including alpha diversity, beta diversity, PERMANOVA, taxonomy plots, and Methods text.
```

## Shotgun metagenomics

```text
Use the shotgun-metagenomics-pipeline skill to plan a reproducible shotgun metagenomics workflow from raw FASTQ files to taxonomic profiles, assembly, binning, MAG QC, functional annotation, and manuscript-ready outputs.
```

## Phage and virome analysis

```text
Use the phage-virome-analysis skill to plan viral contig identification, CheckV quality control, dereplication, taxonomy, host prediction, abundance mapping, and AMG screening for soil metagenomic contigs.
```

## Statistics

```text
Use the microbiome-statistics skill to choose appropriate statistics for microbial community differences across treatments while checking compositionality, batch effects, pseudoreplication, and multiple testing.
```

## Figures and tables

```text
Use the publication-figures-and-tables skill to design a figure plan for a soil microbiome and virome manuscript, including captions and required input tables.
```

## Journal and manuscript support

```text
Use the manuscript-journal-submission skill to prepare a submission checklist and cover-letter outline for a soil phage metagenomics manuscript. Mark journal metrics and author-guideline details as requiring verification.
```

## Literature integrity workflow

```text
Use the literature-discovery-mapper, citation-doi-verifier, journal-integrity-screener, paper-integrity-risk-auditor, and evidence-synthesis-matrix skills to build a verified literature matrix for soil phage effects on microbial communities and carbon or nitrogen cycling.
```
