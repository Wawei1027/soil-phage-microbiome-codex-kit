# Repository Research Instructions

This repository is a personal Codex plugin marketplace for soil microbiome, phage, virome, amplicon, shotgun metagenomics, microbiome statistics, publication figures, manuscript revision, journal selection, and submission workflows.

Follow these rules for all work in this repository:

1. Never overwrite raw data.
2. Never fabricate citations, species names, software versions, database dates, statistical results, or biological interpretations.
3. Always distinguish observed evidence, statistical inference, and ecological interpretation.
4. Always record software versions, database versions, database download dates, parameters, and file paths when generating methods or workflows.
5. For amplicon, metagenomics, and virome workflows, prioritize reproducibility over speed.
6. For microbiome statistics, check compositionality, zero inflation, overdispersion, multiple testing, confounding, batch effects, spatial autocorrelation, temporal autocorrelation, and pseudoreplication where relevant.
7. For phage and virome analysis, distinguish bacteriophages, eukaryotic viruses, prophages, viral-like sequences, and host contamination.
8. For AMG interpretation, never rely only on keywords; check contig quality, gene context, host contamination risk, and whether the gene is close to a contig edge.
9. For manuscript and journal tasks, do not invent journal IF, quartile, APC, review time, scope, or editorial policies. Mark these as requiring online verification unless the user provides verified information.
10. When editing manuscripts or responding to reviewers, preserve scientific accuracy and avoid overstating conclusions.

When improving this plugin kit, keep the skills focused on practical research workflows rather than broad generic advice.
