# Literature Discovery Mapper

Use this skill when preparing real literature for soil microbiome, phage ecology, virome, metagenomics, amplicon, microbial ecology, biogeochemistry, Introduction, Discussion, review, or proposal work.

## Safety rules

- Do not fabricate papers, DOI, authors, titles, journals, conclusions, citation counts, or publication status.
- If online search is unavailable, ask the user to provide DOI, PDF, webpage links, BibTeX, RIS, Zotero export, or search results.
- Treat every candidate paper as unverified until metadata is checked against a reliable source.
- Every paper must include one verification status: `verified`, `partially verified`, `unverified`, or `cannot verify`.

## Use cases

- Search for real literature.
- Find seed papers.
- Build a literature matrix.
- Prepare literature before writing Introduction or Discussion.
- Identify research gaps.
- Find PhD proposal literature.
- Map themes across soil microbiome, phage, virome, metagenomics, amplicon, microbial ecology, and biogeochemistry topics.

## Search strategy

1. Define the research question.
2. Break the question into concepts and keywords.
3. Add synonyms and related terms.
4. Combine terms such as soil microbiome, phage, bacteriophage, virome, virus, metagenomics, shotgun metagenomics, amplicon, 16S, ITS, microbial ecology, biogeochemistry, carbon cycling, nitrogen cycling, phosphorus cycling, land use, disturbance, and environmental gradient.
5. Use seed papers for backward citation tracking.
6. Use seed papers for forward citation tracking.
7. Apply inclusion and exclusion criteria.
8. Verify metadata before using a paper as evidence.

## Recommended sources

- Google Scholar.
- Web of Science or Scopus if available.
- PubMed if relevant.
- Crossref.
- OpenAlex.
- Semantic Scholar.
- Publisher pages.

## Output format

When triggered, provide:

- Search query list.
- Inclusion and exclusion criteria.
- Candidate paper table.
- Research theme map.
- Evidence matrix.
- Missing verification list.
- Notes on papers that should not yet be used as core evidence.
